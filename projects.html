Stylistic LLM fine-tuning Fine-tuning · LoRA

Exploration in nudging an LLM's writing style while preserving factuality and conversational ability. Initial run uses TinyLlama-1.1B-Chat on karpathy/tiny_shakespeare with QLoRA, adapting a small fraction of parameters to keep compute footprint modest.

Approach
QLoRA for parameter-efficient fine-tuning. Comparing prompted style transfer vs. adapter-based fine-tuning for controllability. Working on building a proper eval to compare fine-tuned vs. base model outputs — this is the harder problem.
In progress
Extending to longer training runs, alternative adapter configs, and developing a meaningful eval methodology for style vs. faithfulness tradeoffs.

Quick Draw diffusion model Diffusion · Generative

A compact diffusion training pipeline trained on five categories from Google's Quick Draw dataset (banana, apple, broom, broccoli, birthday cake). Built to understand diffusion model internals — noise scheduling, class conditioning, and the training loop — below the API layer.

How it works
Uses HuggingFace UNet2DModel. Sketches are normalized to 32×32 with padding and combined with a class-indicator channel so the model learns class-conditioned noise prediction across timesteps. Noise scheduler controls timesteps; model predicts noise and is optimized with MSE. Adam with cosine schedule.
